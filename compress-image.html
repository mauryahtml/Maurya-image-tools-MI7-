📖 How to Use

  1. Tap Select Multiple Images and choose one or more images.
  2. Selected images will appear as small thumbnails inside the tool box.
  3. The details of each selected image will be shown below its thumbnail.
  4. Enter the required target size in KB.
  5. Tap Compress Images.
  6. The compressed result will appear inside the same tool box.
  7. Use Download to save an individual compressed image.
  8. Use Share to share an individual compressed image.
  9. Tap Reset All to remove all selected images and results.

🔒 Privacy

MI7 Reduce Image Size in KB processes selected images directly in your browser.
